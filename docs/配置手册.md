# 配置手册

站点配置分布在三处，职责不同，改动前先确认改哪个文件。

| 文件 | 管什么 |
| --- | --- |
| `hugo.toml` | 站点级：地址、语言、输出格式、主题选择 |
| `config/_default/params.yml` | 主题级：菜单、作者、侧边栏、评论、特效 |
| `data/*.yml` | 数据：封面图、友链、第三方 CDN |

> **重要**：主题配置不在 `hugo.toml`，而在 `config/_default/params.yml`。
> Reimu 主题要求把配置文件放在项目根的 `config/` 目录，Hugo 会用它覆盖主题内的同名配置。

## 一、站点配置 hugo.toml

```toml
baseURL = 'https://lushanjun1127.github.io/blog/'  # 站点地址，CI 会覆盖为 Pages 地址
title = '陆山君的博客'                              # 站点标题
theme = 'reimu'                                     # 启用主题，改成 PaperMod 可切回
locale = 'zh-CN'
defaultContentLanguage = 'zh-CN'
hasCJKLanguage = true                               # 中文分词，影响摘要截断
enableRobotsTXT = true

[languages]
  [languages.zh-CN]
    label = '简体中文'
    weight = 1
    hasCJKLanguage = true

[outputs]
  home = ['HTML', 'RSS']
  section = ['HTML', 'RSS']
```

**`defaultContentLanguage` 必须设置。** 只设 `locale` 不够，页面的 `<html lang>` 属性仍会是 `en`，
影响字体渲染和无障碍。这个坑踩过一次。

## 二、主题配置

配置文件是 `config/_default/params.yml`，字段很多，这里只说常用的。

### 基本信息

```yaml
author: 陆山君
description: "记录学习与思考"

subtitle:
  typing:
    enable: false        # true 则启用打字机效果
  text: "记录学习与思考"  # 不打字时显示的副标题
```

### 顶部菜单

```yaml
menu:
  - name: home
    url: ""
  - name: archives
    url: "archives"
  - name: about
    url: "about"
```

`name` 是主题内置的翻译键（对应 `themes/reimu/i18n/` 里的词条），不要随意改成中文，
否则会显示成找不到的键名。要改显示文字，改主题的 i18n 文件或加自己的覆盖文件。

新增菜单项时，`url` 对应的页面必须存在，否则点击后 404：

| url | 对应文件 |
| --- | --- |
| `""` | 首页 |
| `archives` | `content/archives/_index.md` |
| `about` | `content/about.md` |
| `friend` | `content/friend.md` |

### 社交链接

```yaml
social:
  github: https://github.com/lushanjun1127
  # email: mailto:xxx@example.com
  # bilibili: https://space.bilibili.com/xxx
```

可选项见文件内注释（github、bilibili、zhihu、weibo、twitter 等）。

### 侧边栏组件

```yaml
widgets:
  - category      # 分类
  - tag           # 标签
  - tagcloud      # 标签云
  - recent_posts  # 最近文章
```

不需要的删掉即可。

### 评论系统

默认全部关闭。以 Giscus 为例（基于 GitHub Discussions，无需自建后端）：

```yaml
comment:
  default: giscus

giscus:
  enable: true
  repo: lushanjun1127/blog          # 存放评论的仓库
  repoId: <从 giscus.app 获取>
  category: Announcements
  categoryId: <从 giscus.app 获取>
  mapping: pathname
  reactionsEnabled: 1
  emitMetadata: 0
  inputPosition: bottom
  theme:
    light: light
    dark: dark_dimmed
```

配置步骤：访问 <https://giscus.app/zh-CN>，填入仓库名，它会生成 `repoId` 和 `categoryId`，
复制过来即可。其余评论系统（Waline、Twikoo、Valine 等）字段在同文件下部。

### 深色模式

```yaml
dark_mode:
  button: true    # 是否显示切换按钮
  type: auto      # true 默认深色 / false 默认浅色 / auto 跟随系统
```

### 特效

以下特效**默认开启**，若觉得影响性能或体验可关闭：

```yaml
preloader:              # 加载动画
  enable: true

reimu_cursor:           # 灵梦鼠标指针
  enable: true

firework:               # 鼠标点击烟花
  enable: true

animation:              # 滚动入场动画
  enable: true

pace:                   # 顶部进度条
  enable: true
```

### 页脚

```yaml
footer:
  since: 2026
  powered: true      # 显示 "Powered by Hugo & Reimu"
  count: true        # 显示文章数
  busuanzi: false    # 不蒜子访问统计，默认关闭
```

## 三、数据文件

### data/covers.yml

文章未指定 `cover` 时的随机封面池：

```yaml
- https://example.com/cover-1.webp
- https://example.com/cover-2.webp
```

留空（只保留注释）则回退到站点默认头图。

### data/friends.yml

友链列表，配合 `content/friend.md` 中的 `{{< friendsLink >}}` 短代码渲染：

```yaml
- name: 某某的博客
  url: https://example.com/
  desc: 一句话描述
  image: https://example.com/avatar.webp
  badge: 标签
  remark: 备注
```

### data/vendor.yml

第三方库的 CDN 源。国内访问慢时可换成国内 CDN，**一般不需要动**。

## 四、常用定制

### 换回 PaperMod 主题

```toml
# hugo.toml
theme = 'PaperMod'
```

但内容目录结构不同（PaperMod 用 `content/posts/`，Reimu 用 `content/post/`），
切换后需要同步调整，且部分页面（归档页）的实现方式不一样。

### 修改配色

主题色在 `params.yml` 的 `internal_theme` 段，用 CSS 变量定义：

```yaml
internal_theme:
  light:
    --red-0: '#ff0000'    # 主色
    --red-1: '#ff5252'
  dark:
    --red-4: 'rgba(255, 208, 208, 0.5)'
```

改 `--red-*` 系列即可。

### 覆盖主题模板

**不要改 `themes/reimu/` 下的文件**（submodule，升级时会丢）。正确做法是在项目根建同名文件：

```text
layouts/partials/head.html    # 项目根，会覆盖主题的
```

### 添加自定义 CSS

在项目根建 `assets/css/custom.css`，然后在 `layouts/partials/head.html`
（先按上一条从主题复制过来）里引入。

## 五、配置改动后的验证

```bash
# 本地构建，看是否有报错或警告
hugo --minify

# 启动预览，逐页检查
hugo server --bind 127.0.0.1 --port 1313 --baseURL http://localhost:1313/
```

配置类改动建议开分支走 PR，CI 会跑质量门禁。
